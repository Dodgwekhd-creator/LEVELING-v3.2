# LEVELING (v3.2)

An offline-first cognitive training engine and procedural puzzle web application built as a self-contained single-file HTML5, CSS3, and Vanilla JavaScript application.

## Live Demo
Play it directly in your browser: `https://dodgwekhd-creator.github.io/LEVELING-v3/`

## Features
* **Adaptive Protocol (Infinite Procedural Mode):** Dynamically scales across Tiers 1–5 in **Spatial Transformation**, **Working Memory**, **Deductive Logic**, and **Pattern & Math**.
* **Paradox Core (Campaign Mode):** Four structured 10-question trials testing cognitive reflection, probability paradoxes, syllogisms, and lateral reasoning.
* **The Crucible (Error-Recovery Queue):** Automatically captures missed or revealed problems so you can re-attempt and clear them.
* **Skill Profile & Streak System:** Tracks accuracy across all four cognitive domains alongside a daily 3-puzzle goal, streak flame, and earnable Freeze Shields.
* **Offline-First & Zero Dependencies:** Runs natively in any browser without build tools or internet access, with 1-click JSON backup export and import.
